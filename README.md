# playwright-magneto-project
The tests here are apply to the **Register** and **Shipping** functionalities of Magneto, a sandbox that emulates an e-commerce.

In this project I tested the Happy path to create an account **(more negative test cases will be created soon enough).** 

## What I worked on during this small project:

### Base Page:

- Here are the main application's functions to test abstracted with **TypeScript**
- **Objects**, **Classes** and **methods**

### Register form:

- Sign In **End-to-End testing** navigation process: From the final user entering the main URL to the notification of their successfull account created.
- **Locators via POM (Page Object Model)**
- **Assertions** management


### Shipping functionality:

- From selecting an item's color and size, add it to the cart and complete the payment process. Please notice that the tests and test cases for this functionality are still in progress.
